# Marca atopi.ai

Identidad visual de la aplicación: una gotita sonriente con una estrella, en tonos azules, amarillo y coral sobre fondo blanco.

## Contenido

- `hoja-de-estilos-atopi-ai.md`: paleta accesible, tipografía, reglas de uso y variables CSS.
- `assets/atopi-logo.svg`: logotipo horizontal sobre fondo claro.
- `assets/atopi-simbolo.svg`: símbolo solo para fondo claro.
- `assets/atopi-simbolo-oscuro.svg`: símbolo con contorno blanco para fondo oscuro (índigo `#2D2A6E`).
- `assets/atopi-icono-app.svg`: icono de app (también copiado como `web/public/favicon.svg`).

## Notas

- El texto del logotipo usa la fuente **Fredoka**. Si no está instalada, el navegador usará una alternativa; para un uso definitivo, convierte el texto a trazados en un editor vectorial.
- Lienzo de diseño original (privado): https://claude.ai/artifact/LqzmiG4rGtKUCY4eHu99ij
- Las reglas de uso (márgenes, tamaño mínimo, qué evitar) están en la hoja de estilos.
